# 法典笔记（Windows 便携版）

给法学同学用的**离线法条阅读 + 笔记**桌面程序。免安装，双击就能用；笔记存在你自己的电脑里，不联网也不会丢。

---

## 一、我要用（下载即走）

1. 点这里下载最新版：**[fadian-notes-windows-portable-1.0.0.exe](./fadian-notes-windows-portable-1.0.0.exe)**（约 24.7 MB）
2. 双击运行。第一次会被 Windows 拦一下（因为程序没买数字签名），点 **更多信息 → 仍要运行** 即可。
3. 详细图解见 👉 **[使用说明书.md](./使用说明书.md)** 第 1 节。

**文件校验值（SHA256）**，可用于确认文件没被篡改或下载不完整：

```
E77504E0E0E2AD85A29C43AA193F8CD25A47AC2268AF8A97017069AD7CDAB52F
```

计算方式（Windows 自带 PowerShell，复制粘贴回车）：

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\fadian-notes-windows-portable-1.0.0.exe" -Algorithm SHA256
```

两串字符一模一样 → 文件没问题。

## 二、我要改（改文字 / 改界面 / 提建议）

先读 **[使用说明书.md](./使用说明书.md)** 第 2 节，按里面的"方式一（网页上直接改）"或"方式二（GitHub Desktop）"操作就行，全程不需要装开发工具。

改的是 `源码/网页/` 里的文件；改完在浏览器里双击就能看到效果，不用等打包。

## 四、说明与免责

- 程序内含的法条文本来自公开发布的法律文本，本仓库仅供**校内学习交流**使用。
- 程序未做数字签名，首次运行会出现 SmartScreen 提示，属正常现象；介意的话可以只使用 `源码/网页/法典笔记.html`（用 Edge 直接打开，功能基本一致）。
- 笔记数据保存在本机，位置见说明书 1.4 节；换电脑或重装系统前请先导出/备份。
