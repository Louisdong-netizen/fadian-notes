法典笔记 3.8 · Mac 完整版
========================

构建号：2026111102
版本号：3.8
构建日期：2026-11-11

本次更新
--------
- 每条法条成为一张独立的纸：独立纸张背景、桌面 32px / 窄屏 20px 的纸张间隔；
  无边框、圆角、阴影或分割线，长正文随内容自然增长。
- 彻底移除“随文笔记”：删除法条下方笔记区、空邀请、显示模式和“笔记默认显示”设置；
  全部笔记只在右侧栏显示和管理。
- 右侧栏顶部新增“当前阅读法条”面板，跟随左侧滚动自动更新，并始终提供新建笔记入口。
- 新建笔记读取当前滚动位置对应的法条，不再沿用上一次的法条编号。
- 保留原有文本选中、复制、批注、高亮、笔记保存、检索和阅读位置机制。

本包内容
--------
1. 法典笔记.app
   当前已安装、可直接运行的完整 Mac 应用。

2. 安装包/
   法典笔记-3.8-macOS.dmg

3. 源码/

   build.sh      Mac 构建脚本
   Info.plist    应用元数据

安装
----
- 推荐：打开 安装包/法典笔记-3.8-macOS.dmg，将「法典笔记.app」拖到「应用程序」。
- 或直接运行本包顶层的「法典笔记.app」。
- 本应用为本地 ad-hoc 签名，未做 Apple 公证；首次打开如被 Gatekeeper 拦截，
  可在 Finder 中右键应用 → 打开。

数据位置
--------
笔记保存在本机 WebKit 数据目录，不上传云端。
应用更新不会删除已有笔记；更换应用包前可先在「导出同步」中导出 JSON 备份。

重新构建
--------
在「源码」目录运行：
  ./build.sh
需要 Xcode Command Line Tools（swiftc、codesign、hdiutil、pkgbuild、productbuild）。
