法典笔记 3.8 · 条文关系说明

3.0 起，每条法条正文下方有「自动关联」面板，分「本法相关」与「其他法典相关」；3.5 把查看方式改成大框对照：点条号、或点「＋采纳」，都会弹出两栏条文原文，限高、各自滚动、共同术语高亮。

一、线索从哪来（按可信度从高到低）

标签 怎么来的 可信度 怎么核对
明文援引 条文里写明的「本法第 X 条」 最高，法条自证 直接用条文原话核对
被援引 反向：本条被哪一条点名 同上 同上
概念衔接 人工锚定的教科书级桥接（如民法典 1034 ↔ 刑法 253） 高，但带编辑判断 看右列的说明文字
同一节 / 同一章 / 同一编 编章节结构位置 高，但只说明位置相近 看目录层级
前后条 相邻条号 高，制度上常连贯 读上下条
内容相近 法律术语共现 + 文本相似度 中，是线索不是结论 看右列共享术语，再读原文
主题接近·推断 只有文本相似度，未共享术语 低，仅作提示 必须自己判断

程序不会替你下结论：面板末尾的说明已写明「供线索用，可能不全或不准」。

「概念衔接」= 人工锚定，共 137 组（双向计 266 条），每条都有可读的理由，例如：

  • 民法典 1034（个人信息）↔ 刑法 253（侵犯公民个人信息罪）、宪法 40（通信自由和通信秘密）
  • 民法典 187（责任竞合）↔ 刑法 36（民事赔偿优先）
  • 民法典 1165（过错责任）↔ 刑法 14、15（故意与过失）
  • 刑法 246（侮辱诽谤）↔ 宪法 38（人格尊严）、宪法 35（言论自由）

并非每条都有跨法典线索：民法典有 456 条、刑法有 117 条、宪法 40 条找不到可靠的跨法域关联，此时面板会显示「未找到可靠的跨法典关联」，并提示用手动关联。这是有意为之——宁缺勿滥（例如物权编的技术性条文，其他三部法典里本来就没有对应制度）。

三、怎么用

  1. 双击 打开法典笔记.html，或直接双击任一部法典。
  2. 进入「法条精读」，搜索条号（如「第一千零三十四条」）。
  3. 正文下方的「自动关联」：
    • 点本法相关的条号：弹出大框对照（本条 ↔ 那一条）；
    • 点其他法典相关的「《刑法》第二百五十三条」：同样弹出对照，左本法、右对方；
    • 两栏各自滚动，Esc 或「关闭」退出；
    • 对照底部点「在刑法中打开 ↗」：跳到对方页面那一条；
    • 点「＋采纳」：先存入「跨法典关联」，随即弹出同一组对照，按钮变「已采纳 ✓」。
  4. 笔记照旧分开存放，四部法典互不覆盖。

提示：每条法条本身就有固定网址（#a1034 或 #ref=第一千零三十四条），可以直接发给别人。

四、条文对照：怎么读

3.5 起，点条号或点「＋采纳」，都直接弹出大框对照（不再是页内小条）：

┌ 条文对照 ─────────────────────────── 左：本法 · 右：关联条文 ── 关闭 ┐
│ 对照 · 概念衔接 · 共同术语：个人信息                                  │
│ 民法典 第一千零三十四条        │ 刑法 第二百五十三条                  │
│ 3 款 · 151 字                  │ 4 款 · 223 字                        │
│ 自然人的「个人信息」受法律保护…│ 之一 违反国家有关规定…「个人信息」…  │
│                             ↑ 两栏各自滚动，框体限高            │
│ [＋采纳为关联] [在刑法中打开 ↗]                        两栏各自滚动·Esc 关闭 │
└──────────────────────────────────────────────────────────────┘
  • 限高 + 内部滚动：框体最高约 90% 屏高，每栏最高 58% 屏高；长条文（如刑法 383 条量刑）只在栏内滚动，页面本身不被撑长。
  • 点「＋采纳」的流程：先写入「跨法典关联」→ 随即弹出同一组对照 → 按钮变「已采纳 ✓」。也就是说，采纳这个动作本身就会让你看到两条原文，而不是只留一个名字。存下的记录会在正文末尾的「相关条文」块里，点它同样直接弹出对照；在精读页右上角点「建立关联」可以手动补充。
  • 「建立关联」也能跨法典：精读页右上角的「建立关联」弹窗顶部多了一个「法典」下拉，选宪法／刑法／网络安全法后，可按完整条文列表选条、即时看到对方正文、写好理由保存；保存后同样立刻弹出对照，记录进入「相关条文」与「跨法典关联」页。选「本法典」时仍是原来的同法典关联。
  • 误建的关联可以逐条撤销：「相关条文」块里每条右边有「撤销」，只删这一对；同一法条与其他条文的关联保留。撤销前会弹窗写明将移除哪一条、还剩几条，确认后才执行；原文、笔记、材料库不受影响。
  • 栏头固定：向下滚动时，「民法典 第 X 条 / 3 款 · 151 字」停在栏顶，不会跟丢。

读法建议：

  1. 先看共同术语（黄色底纹）——它说明两条为什么被连起来。若无底纹，说明这条只是结构相邻或措辞相近，含金量低。
  2. 再看款数——一边 1 款、一边 5 款，通常意味着「原则—具体」的关系，而不是平行关系。
  3. 最后自己判断：程序只负责把两条摆在一起，是否成立、成立到什么程度，是读的人的事。

跨法典对照需要在页面里内嵌对方条文，实测代价很小（去重后）：宪法 +33 KB、民法典 +117 KB、刑法 +69 KB、网安法 +31 KB，四页合计约 0.24 MB。因此仍然是单文件、双击即用、不联网。

五、刑法文本状态与一处必须知道的缺陷

已合并《刑法修正案（十二）》（2023-12-29 通过，2024-03-01 施行）。按最高人民检察院公布的新华社稿，第 165、166、387、391、393 条已更新正文；刑法页的版本年份也随之标为 2024 年文本。

必须说明的缺陷：本页刑法正文来自条文库，而该库对带「之一」的条文有编号错位——第 X 条之一的内容被放到了第 X 条的位置，第 X 条本体没有收录。已核实的例子：第 133 条位置显示的是 133 条之一（危险驾驶罪），第 253 条位置显示的是 253 条之一（侵犯公民个人信息罪），第 169、390 条同理。

修正案（十二）恰好涉及 169、390 两条，因此这两条在本页无法直接替换正文，改以条上方「文本说明」给出修正后的新增款项；其余 5 条（165、166、387、391、393）已按官方文本替换。

彻底修好需要从官方完整文本重建刑法页（约 480 个条文，含全部「之一」）。这是下一步最该做的事，涉及约 30 处编号，工作量约 1 天。

六、跨法典检索

「自动关联」面板右上角有「跨法典检索」：输入一个关键词（如「个人信息」「违约金」「正当防卫」），一次在宪法、民法典、刑法、网络安全法四部法典的条文正文中查找，按命中次数排序，显示条文号与上下文片段，点「打开 ↗」跳到那一条。

四部法典的条文正文都内嵌在页面里，所以检索是本地即时的，不联网、不调模型。

七、已知局限

  1. 关系是算法 + 人工锚定的产物，不是官方发布的「法条关联」。涉及课程论文、竞赛提交时，请以条文原文为准。
  2. 未覆盖司法解释、地方性法规、其他部委规章；跨法域线索只在宪法、民法典、刑法、网络安全法四部之间生成。
  3. 语义关系偏向「用词相近」，对立法目的、体系解释层面的联系只能提供线索。
  4. 刑法页存在上文第五节的「之一」编号缺陷，涉及其余「之一」条文时请核对官方文本。
