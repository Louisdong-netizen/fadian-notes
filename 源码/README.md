# 源码 · 网页

这里是法典笔记的**界面与内容本体**——程序的"配方"，exe 只是把它打包后的成品。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `法典笔记.html` | 主程序（综合法典笔记，最大的那个） |
| `法典笔记-civil-code.html` | 民法典分册 |
| `法典笔记-criminal-law.html` | 刑法分册 |
| `法典笔记-cyber-law.html` | 网络安全法分册 |
| `app-home.html` | 首页 / 入口页 |
| `打开法典笔记.html` | 本地启动入口（用浏览器打开它也行） |
| `使用说明.html` / `使用说明.md` | 程序内置的使用说明 |
| `关系说明.html` / `关系说明.md` | 法条之间关系的说明页 |
| `pdf.min.js` / `pdf.worker.min.js` | 导出 PDF 用到的第三方库（别删，删了导出会坏） |
| `app-icon.png` | 图标 |

## 怎么改、怎么看效果

1. 用**记事本**或 **VS Code** 打开要改的 `.html`（**不要用 Word**，Word 会破坏文件）。
2. 改完保存（`Ctrl + S`）。
3. **双击 `法典笔记.html`**，用 Edge/Chrome 打开，就是改完后的界面——可以立刻看效果，不需要打包。
4. 看着没问题，再按 `使用说明书.md` 第 2 节上传（发 PR）。

## 注意

- **文件名不要改**（尤其中文名），程序内部靠这些名字互相跳转。
- 四个大 HTML 每个 3～4 MB，一次只改一处、改完就提交，别攒一大堆（改动越大越难审核、越容易冲突）。
- 想把这些改动变成"同学能双击下载的新 exe"，需要管理员在本机重新打包并发 Release，见 `使用说明书.md` 第 3.3 节。
